# Pocket Plan (Android APK)

1. Create a free account at github.com and make a new repository (any name).
2. Upload everything in this folder: www, .github, package.json, capacitor.config.json.
   If the .github folder is skipped, click Add file > Create new file, type
   .github/workflows/android.yml as the name and paste the contents of that file.
3. Open the Actions tab. The build starts by itself (about 5 to 10 minutes).
   You can also press Run workflow.
4. When it turns green, open the run and download pocket-plan-apk under Artifacts.
5. Unzip it, send app-debug.apk to your phone, open it and allow installing from this source.
